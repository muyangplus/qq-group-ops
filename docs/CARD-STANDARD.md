# 卡片标准（Card Standard v2）

> 本文件自 2026-09-26 起为**正式规范（v2）**；v1 的旧版内容见 git 历史（提交 `2c502f2` 之前）。
> 与 v1 的差异：① 引导行 `buttonHint` 全部废弃（模板不再渲染）；② 卡片正文**禁止**写指令用法，一律进 `/help`；
> ③ 能一键完成的动作必须是按钮（含「查看详情」这类导航）；④ 群内首行 @ 固定放标题下一行。
> 动因：真机反馈暴露了三类问题——① 卡片里堆指令用法（超管菜单最典型）；② 按钮能做到的事还写成文字（“查看详情：/activity info #短码”）；
> ③ 空态引导不够直接（个人资料未设置时逐个字段引导，而不是给一条能直接发的组合指令）。

## 1. 第一原则：按钮优先

判断顺序（每张卡都必须走一遍）：

1. **能一键完成 → 用回调按钮**（导航、翻页、开关、切换、固定动作）；
2. **需要参数 / 不可逆 → 用指令按钮**（预填指令，用户补参数；不可逆再加二次确认）；
3. **只有“按钮无法表达”的东西才写进正文**：状态、数量、原因、名单、时间、短码；
4. **指令用法一律不写进卡片**，统一放 `/help`（含每个主题的详细用法）；
5. **纯文本降级不算卡片文案**：`cardTemplate` 会自动把指令按钮的 `command` 列进 `text` 兜底，回调按钮由正文里的“等价指令”承担——
   但只在**没有对应按钮**时保留（例如活动成员的“报名 / 取消报名”兜底）。

反例 → 正例：

| 反例（现文案） | 正例 |
|---|---|
| `查看详情：/activity info #TMUV2J` | 删掉该行，加「查看详情」按钮（`cb:activity:info:#TMUV2J`） |
| 超管菜单 10 行 `查询映射：/whois … / 绑定用户：/bind …` | 删掉全部文字；按钮「权限 / 全局规则 / 别名 / 通知订阅 / 处罚推送 / 全局黑名单 / @测试 / 帮助」 |
| 审核操作卡 5 行 `/approve … / /reject …` | 删掉；按钮「待审批 / 同步 / 处罚记录 / 黑名单 / 返回」；用法在 `/help approve` |
| 个人资料空态“请用下面按钮补全” | “请发送一条组合指令：`/profile set <学号> <班级> <姓名>`” + 一个预填 `/profile set ` 的按钮 |

## 2. 硬规则（模板已强制 + 评审必查）

| 规则 | 数值 | 说明 |
|---|---|---|
| 标题 | ≤ 20 字 | `## 标题`，纯文本降级为 `【标题】` |
| 正文 | 每行 ≤ 100 字 | 只放状态/数值/原因/名单 |
| 按钮行 | ≤ 5 行 | 官方上限 |
| 每行按钮 | ≤ 5 个，且**整行文字 ≤ 12 字** | 模板已强制 |
| 单个按钮文字 | ≤ 10 字 | 模板会截断 |
| 群内首行 | 标题下一行 `<@!发起人>` | §F1；私聊不加；已带 @ 的卡不重复 |
| 引导行 | 尽量不用 | 需要时 ≤ 6 字（如「请选择功能：」） |

## 3. 卡片分类与结构模板

| 类型 | 用途 | 结构 | 示例 |
|---|---|---|---|
| **导航卡** | 菜单 / 子菜单 | 标题 + （可选 0-1 行状态）+ 按钮 | 常用菜单、管理菜单、超管菜单 |
| **操作卡** | 管理动作 | 标题 + 状态行 + 动作按钮（危险动作用红色 + 二次确认） | 活动配置卡、规则子卡、处罚卡 |
| **结果卡** | 动作回执 | 标题 + `**结果**：…` + （必要数据）+ 返回按钮 | 已通过审批、已调整禁言 |
| **列表卡** | 多条目 | 标题 + 编号列表（每页固定条数）+ 翻页/条目按钮 | 待审批、审计、名单、黑名单 |
| **隐私卡** | 个人数据 | 群内只私信；正文只放数据行；按钮覆盖所有动作 | `/whois`、`/profile`、`/myperm` |
| **通知卡** | 主动推送 | 标题 + 关键信息 + 动作按钮（拉黑/解除等）；不含指令说明 | 入群申请、处罚通知、申诉通知 |

## 4. 菜单重构原则

1. **菜单只做导航**：一级/二级菜单不解释自己怎么用，不列指令；
2. **用法去 `/help`**：每个菜单卡片对应一个 `/help <主题>` 按钮（超管菜单 → `/help perm`）；
3. **入口按权限生成**：无权不生成按钮；越权只提示所需权限（不展示内容）；
4. **默认入口=常用菜单**（§F2）：群里不出现管理/超管入口，超管菜单仅私信；
5. **一层能解决的不要拆两层**：子菜单存在的唯一理由是“按钮放不下”。
