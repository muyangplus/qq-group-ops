# Roadmap

本项目按阶段推进。每个阶段都必须有明确的可交付物和退出条件，未通过退出条件不进入下一阶段。

## 阶段总览

| 阶段 | 目标 | 状态 |
|---|---|---|
| Phase 1 | 实现 MVP 核心：入群审核、消息规则、审计日志 | 进行中（服务层与网关已完成） |
| Phase 2 | Web 管理后台、内容安全、群邀请/好友审核 | 待开始 |
| Phase 3 | AI 辅助审核、举报申诉、统计报表 | 待开始 |
| Phase 4 | 安全加固、文档完善、开源发布 | 待开始 |

## Phase 1：MVP 核心

**目标**：实现可运行的最小可用版本。

**范围**：

- 配置加载与校验。
- `QQOfficialClient` 官方 REST 调用封装。
- 官方 WebSocket / Webhook 网关（含自动重连、退避与限流冷却，见 ADR-0023）。
- 入群申请审核：QQ 指令通过 / 拒绝（已打通官方审批接口与自动通过，见 ADR-0024）；规则化审核（班级库 + 班级/姓名/正则匹配 + 决策模式，见 ADR-0032）。
- 消息规则引擎：关键词、正则、白名单、动作映射（群配置关键词已接入，见 ADR-0024；撤回/禁言/移出/拉黑动作见 README）。
- 消息处理：警告、记录、撤回（如果官方能力允许）。
- 入群申请推送：`/notify` 订阅 + Markdown 卡片 + 快捷同意/拒绝按钮（见 ADR-0034）。
- 管理员命令：`/rules set` 群规则配置、`/audit` 审计查询、`/sync` 官方申请同步（已完成）。
- OpenID ↔ QQ号/群号绑定：数据库持久化（已完成，见 ADR-0020）。
- 全部状态持久化：权限、审计、入群申请、群配置、全量消息模式、活动报名（已完成，见 ADR-0021）。
- 数据库默认 SQLite、可选 PostgreSQL（已完成，见 ADR-0022）。
- 审计日志：持久化并可查询。
- 多群配置：统一默认 + 单群覆盖。
- Docker Compose 部署。
- 单元测试与基础 CI。

**退出条件**（逐项验收步骤见 [ACCEPTANCE.md](ACCEPTANCE.md)）：

- [ ] 测试群中可以完成一次入群申请审批闭环。
- [ ] 关键词命中后可以按规则执行动作并记录日志。
- [ ] 审计日志可持久化、可查询。
- [ ] `pnpm typecheck`、`pnpm test`、`pnpm build` 全部通过。
- [ ] Docker Compose 可以启动 bot 与数据库。
- [ ] README 中的快速开始步骤可复现。

## Phase 2：Web 后台、内容安全与活动运营

**目标**：把管理能力从 QQ 指令扩展到 Web 后台，并支持活动报名与信息导出。

**范围**：

- Fastify / Node.js 管理 API + 登录鉴权。
- Vue 3 + TypeScript 管理后台。
- 审核队列、规则配置、日志查询、权限管理。
- 文本内容安全 API。
- 图片 / 文件 / 链接审核（以官方能力为准）。
- 好友申请 / 群邀请审核（以官方能力验证结论为准）。
- 活动报名：活动创建、报名收集、名单管理、签到统计。
- 信息导出：审核日志、报名名单和活动数据导出（带权限校验与脱敏）。

**退出条件**：

- [ ] 公网后台具备登录鉴权、限流和最小权限。
- [ ] 可以在 Web 后台完成入群审批、规则配置和活动报名管理。
- [ ] 内容安全 API 接入并有误报/漏报处理策略。
- [ ] 信息导出有权限校验和数据脱敏。

## Phase 3：AI 与运营

**目标**：在规则稳定后引入 AI 辅助。

**范围**：

- AI 判断入群理由。
- AI 辅助疑难内容审核。
- 举报与申诉流程。
- 统计报表与自动化策略。
- 只把可疑内容送入大模型，控制成本。

**退出条件**：

- [ ] AI 只作为辅助，保留人工复核入口。
- [ ] 有误判申诉和回滚机制。
- [ ] 成本在可接受范围内。

## Phase 4：安全加固与开源发布

**目标**：达到可长期维护的开源项目质量。

**范围**：

- 安全审计与依赖更新策略。
- 数据保留、删除和导出机制。
- 完整文档、示例配置和部署指南。
- 版本发布流程与 CHANGELOG。
- 贡献者指南和 Issue/PR 模板。

**退出条件**：

- [ ] 安全与合规检查清单完成。
- [ ] 至少一次完整部署演练和备份恢复演练。
- [ ] 发布首个可用的 GitHub Release。
